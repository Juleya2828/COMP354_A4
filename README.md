# COMP354_A4

## Assignment Objectives
The objective of this assignment is to gain practical experience with Software
Configuration Management (SCM) using Git and GitHub.

By completing this assignment, you will demonstrate your ability to:
- Manage distributed repositories using forks, clones, and remote
synchronization.
- Collaborate on an existing software project using branches, commits, and pull
requests.
- Review and integrate changes through a controlled GitHub workflow.
- Identify, resolve, and document Git merge conflicts.
- Verify that changes to an existing codebase have been integrated correctly.

The primary focus of this assignment is Git and GitHub collaboration, rather than
advanced Python programming.
